Hisaab documentation

Hisaab is a business operations admin dashboard: sales, CRM, orders, products, customers, invoices, a calendar and a task board in 18 pages. It is made with plain HTML, CSS and vanilla JavaScript. There is nothing to install and no build step: open a file in your browser and it works. Version 1.0.0.

Getting started

  1. Unzip the download.
  2. Open the Hisaab folder and double-click index.html. The dashboard opens in your browser.
  3. Open any .html file in a code editor such as VS Code to change text, numbers and links.

Everything works offline. Fonts, icons and charts are included in the package, so the template does not load anything from the internet.

Change colours and logo

All colours are CSS variables at the top of assets/css/style.css. To rebrand, change the four brand variables below. The first two chart colours follow --primary and --accent automatically. Dark mode has its own lighter versions of the same variables in the [data-theme="dark"] block just below; change those too.

:root {
  --primary: #0f6e5a;        /* buttons, links, active menu, charts */
  --primary-strong: #0a5545; /* hover state */
  --primary-soft: #e3f1ec;   /* light backgrounds */
  --accent: #d9922e;         /* highlights */
}

Chart colours use --c1 to --c5. The logo is an inline SVG in each page (search for brand-mark) and a file in assets/img/logo.svg. Replace both with your own logo.

Fonts

Headings and figures use Bricolage Grotesque; interface text uses Instrument Sans. Both are included as .woff2 files and loaded with @font-face in section 1 of style.css. To use another font, add its file to assets/fonts and change --font-display and --font-ui.

Dark mode

The moon button in the top bar switches themes. The choice is remembered in the browser. On the first visit the template follows the visitor's system setting. To force one theme, change data-theme="light" on the <html> tag and remove the small script in the <head>.

Sidebar menu

The menu is a plain list of links inside <nav class="nav">. Add a link by copying an existing one. Mark the current page with class="active" and aria-current="page". The collapse button in the top bar shrinks the sidebar to icons on desktop; on phones the menu opens as a drawer.

Charts

Charts are drawn by assets/js/charts.js from a JSON object in the data-chart attribute. They redraw on resize and when the theme changes, and show a tooltip on hover.

<div class="chart" data-chart='{
  "type": "area",
  "height": 280,
  "prefix": "$", "suffix": "k",
  "labels": ["Jan", "Feb", "Mar"],
  "series": [
    {"name": "This year", "data": [42, 48, 45]},
    {"name": "Last year", "data": [38, 40, 41], "color": 2, "dashed": true}
  ]
}'></div>
  • type: line, area, bar, stacked, donut or spark.
  • Donut charts use values and labels instead of series. Optional centerValue and centerLabel set the text in the middle.
  • color picks a palette colour by number (0–4).
  • Redraw a chart from your own code with HisaabCharts.render(element).

Interactive components

Every feature is switched on with a data- attribute, so you can copy markup between pages. See components.html for working examples.

Tabsdata-tabs on the wrapper; buttons with role="tab" and aria-controls

Keyboard: Esc closes menus and modals, Ctrl + K or / focuses search, arrow keys move between tabs.

Forms and validation

Add data-validate to a <form>. Fields with required are checked on submit and an .error-text message after the field is shown when it is empty or invalid. Use data-success="Message" to show a toast and data-redirect="page.html" to go to another page after a valid submit.

All forms are front-end only: they check the fields in the browser and show a message, but nothing is sent or saved. To store data, send the form to your own backend or a form service.

Demo data and limits

Hisaab is a front-end template. It has no server, database, user accounts or payment system, so nothing you do in the demo is saved.

  • Where the demo data lives: names, orders, products and invoices are written directly in each HTML file. Edit or delete the table rows and cards to use your own data. Chart numbers are in the data-chart attribute (see Charts), and calendar events are in the JSON block inside calendar.html.
  • Added and changed items (new orders, products, customers, invoices, deals, tasks, events and status changes) appear straight away but disappear when the page is reloaded. Connect your own backend or API to store them.
  • Works fully in the browser: search, filters, sorting, pagination, CSV export, theme switching, the calendar, the kanban board and form validation.
  • Needs your backend: signing in and creating accounts (the auth pages only check the fields and open the dashboard), sending emails and reminders, saving settings, importing CSV files (the demo only reads the file and counts the rows) and updating payment cards.
  • Terms and privacy: the sign-up page mentions Terms of service and a Privacy policy as plain text. Link them to your own pages when you publish.

Publishing your site

Upload the contents of the Hisaab folder to any web host: cPanel, Netlify, Vercel or GitHub Pages. No server code is needed.

Browser support

Latest versions of Chrome, Edge, Firefox and Safari, on desktop and mobile. Internet Explorer is not supported.
